# SocratiCode V

Локальный поиск по коду для Windows. Приложение предоставляет MCP, ищет по смыслу и точным фрагментам, строит граф связей и обновляет индекс после сохранения файлов. Codex подключается через отдельный локальный плагин. Предыдущая версия с Docker сохранена в [legacy](legacy/README.md).

## Сборка и запуск

Для сборки нужны Node.js 24, установленный MSVC с Windows SDK и зависимости из корневого lock-файла. Qdrant, Ollama и модель Jina размещаются в `runtime/`. Скрипт `windows/provision.mjs` принимает путь к подготовленному каталогу с `bin/qdrant-1.20.2`, `bin/ollama-0.40.19` и `data/models` и размещает эти зависимости локально. После подготовки сборка и запуск используют файлы из корня этого репозитория.

```powershell
npm ci --cache .cache/npm
npm run build
npm start
```

Готовое приложение находится в `runtime/bin/SocratiCodeV.exe`. Его можно открыть из Проводника или запускать по запросу MCP. По правому клику на значке в трее доступны цветной и монохромный режимы, журнал и выход. Значок подстраивается под тему панели Windows, выбранный режим сохраняется. Индексы лежат в `runtime/data`, модель в `runtime/models`.

## Codex

```powershell
codex plugin marketplace add .
codex plugin add socraticode-v@socraticode-v-local
```

Плагин берётся из `plugins/socraticode-v` этого репозитория. В новом чате агент увидит MCP `scv`. Для MCP нужен `mcp_2026_07_28 = true` в `[features]` Codex. Доверенный хук начала сессии может прогреть уже настроенный проект. Готовность инструментов от хука не зависит. На новый проект запрашивается согласие, затем сохраняются правила и проверяется область индекса.

## Исходники

- `windows/` — оболочка C++/Win32, локальная сборка, настройки SQLite и тесты Windows.
- `src/` — общая логика поискового сервера на TypeScript, которую использует Windows-сборка.
- `plugins/socraticode-v/` — плагин Codex с инструкциями и логотипом.
- `legacy/` — предыдущий SocratiCode `1.16.1-local.9` из `49ef3fa` с прежними плагинами и Docker. Сборка из корня использует собственные исходники.

```powershell
npm test
npm run test:codex
```
