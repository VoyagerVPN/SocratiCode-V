# SocratiCode V

Выбирай инструменты сервера `scv`. Передавай проверенный абсолютный корень проекта как `projectPath` в каждом запросе. Для известного файла прочитай нужный участок напрямую.

- Для поиска по смыслу или по словам начни с `codebase_search` в режиме по умолчанию. Для точного фрагмента, включая пунктуацию, используй `mode: "exact"`.
- Для связей между файлами используй `codebase_graph_query`. Для определений, вызовов и оценки влияния правки используй `codebase_symbol`, `codebase_flow` или `codebase_impact` по задаче.
- Когда инструмент сообщает об отсутствии индекса, вызови `codebase_setup` с `action: "inspect"`. Если каталога ещё нет, вернись к настройке после его создания. Если состояние неизвестно, продолжай задачу прямым чтением и уточняй состояние только при необходимости.
- Если каталог существует и индекса ещё нет, один раз спроси пользователя, нужны ли индекс и граф. После согласия проверь структуру проекта и `.gitignore`. Сохрани правила `.socraticodeignore` через `codebase_setup` с `action: "save"`. Оставь исключения для `node_modules`, `.lab`, `.tmp`, `.temp` и `.cache`. При необходимости разреши конкретный путь через `includePaths`; зависимости в `node_modules` исключай всегда. Проверь область через `action: "preview"`, затем один раз вызови `codebase_index`.
- После первого построения watcher сам обновляет поиск и граф при сохранении. Если результат помечен как обновляемый или частичный, сверяй нужные строки с файловой системой. При недоступности SCV продолжай работу по файлам и возвращайся к MCP, когда он доступен.
