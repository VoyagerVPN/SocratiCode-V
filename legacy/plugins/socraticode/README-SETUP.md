# SocratiCode V — установка

Исправленная локальная сборка с Jina v5 Nano Retrieval, общим stateless HTTP, компактными ответами и ограничением объёма индексации. Пакет содержит готовую сборку и исходники. Подключение предназначено для локального Codex с MCP 2026-07-28 и поддержкой SessionStart-хуков.

Распакуйте `socraticode/` в постоянную папку. Установите Node.js >=20 и запустите Docker Desktop с Linux-контейнерами. Для включённого GPU-профиля нужна доступная Docker NVIDIA GPU.

Откройте эту папку в Codex и напишите агенту:

> Прочитай AGENTS.md и установи этот SocratiCode на моей машине. Сохрани мой профиль Codex, подключи плагин и проверь русский поиск, GPU и пять одновременных клиентов. Не заменяй сборку официальным npx SocratiCode.

Агент установит зависимости через `node install-dependencies.mjs`, проверит их через `node setup.mjs --check`, зарегистрирует папку сервера командой `node setup.mjs`, затем подключит локальный marketplace и проверит работу в клиенте. Разрешение SessionStart-хука потребуется в интерфейсе Codex.

Пакет нельзя удалять после установки: сервер и зависимости остаются в его `server/`, а хук установленной копии находит их через локальную запись в домашнем каталоге. После перемещения повторите `setup.mjs`. Сам архив не содержит индексов, Docker volumes, модели, node_modules, кэшей, истории или профиля автора. Образы, модель и зависимости скачиваются на машине получателя.

Адрес MCP — `http://127.0.0.1:16335/mcp`; Qdrant — 16333, Ollama — 11435. Не запускайте второй SocratiCode на тех же портах. Лицензия исходного проекта AGPL-3.0-only сохранена в `LICENSE` и `server/LICENSE`; исходники этой сборки включены в `server/src`.
